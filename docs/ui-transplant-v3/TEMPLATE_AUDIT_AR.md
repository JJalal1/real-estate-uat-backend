# تدقيق حزمة eBroker المرفقة

تاريخ الفحص: 11 أكتوبر 2026. هذا تدقيق قراءة فقط وتجهيز مرجع مستقل؛ نقل الواجهات لم يبدأ.

## الحزمة والإصدار الفعلي

وصل `eBroker 1.8.0.zip` بحجم 155343094 بايت. بصمته:

`86de3f3c25ed3a43897eb0f49a910ff17f75aecba6eb7baebb113dc3d389372c`

يحتوي أربعة أجزاء رئيسية: تطبيق Flutter، لوحة Laravel مع نسخة تثبيت جديدة وأرشيفات تحديث، موقع Next.js، ووثائق. فحصت ZIPs داخليًا دون تشغيل installer أو تفعيل أو تثبيت اعتماداته أو بناء القالب.

| الجزء | الحقيقة المثبتة من ملف المصدر |
|---|---|
| تطبيق Flutter | `pubspec.yaml`: الإصدار `1.8.0+88`، Dart `^3.10.0` |
| موقع الويب | `package.json`: الإصدار `1.8.0`، Next `^16.2.6` وReact `^19.2.6` |
| لوحة الإدارة | `composer.json`: PHP `^8.1.0` وLaravel `^10.0`؛ لا يحدد إصدار المنتج نفسه |
| بيئة مشروعنا | Flutter `3.27.3` مع الاعتمادات الأصلية؛ لا تتبنى متطلبات بناء القالب |

بصمات كل ZIP فرعي محفوظة في `ebroker-audit-summary.json`، ومنها ZIP التثبيت الجديد داخل أرشيف الإدارة. أرشيفات تحديث الإصدارات القديمة تبقى ضمن الحزمة الأصلية المرفقة؛ لم تعتمد ضمن مرجع المصدر المنقح للنسخة 1.8.0.

الملفات المشمولة محفوظة بايتًا ببايت؛ لم تجر إزالة أسرار داخل ملف ثم وصفه بالأصل. نسخة الحزمة الأصلية المرفقة بقيت كما وصلت، خارج هذا المرجع المنقح.

## الإعدادات والخصوصية

استبعدت ملفات البيئة وأمثلتها، إعدادات Firebase والتوقيع والإعدادات الخاصة، مجلدات المنصات غير اللازمة لمرجع UI، الاعتماديات والمخرجات والبيانات التشغيلية والبذور، صور توثيق قد تعرض إعدادات، وشهادات الشراء والتفعيل. الشهادة والصور المرفقة منفصلة عن ZIP المصدر ولا تدخل إلى المرجع.

فحصت جميع المداخل الـ2006 في ZIP المنقح: 2005 ملفات أصلية مشمولة وبيان التدقيق. لم يجد فحص الأنماط مفاتيح خاصة أو Google API keys أو JWT أو service-account definitions أو روابط اتصال تتضمن بيانات اعتماد. ولم يجد فحص القيم المطابقة من الشهادة رمز الشراء أو اسم صاحبها ضمن هذه المداخل. هذه فحوص محددة وليست ضمانًا لاستحالة وجود أي نوع من البيانات الحساسة.

## نتائج تؤثر في التلبيس

- Home وبطاقات القالب مرتبطة بـCubit وHive وأقسام بيانات القالب وإعلاناته. يؤخذ تكوينها البصري ويعاد ربطه ببياناتنا وRiverpod، ولا تنقل الأقسام أو الإعلانات كميزات جديدة أثناء المطابقة.
- تفاصيل العقار في القالب مرتبطة بآليات appointment وsubscription وAdMob. تبقى إجراءات مشروعنا ونماذجه وعقود API والصلاحيات حاكمة.
- يوجد في `property_contact_buttons.dart` اتصال مباشر عبر `tel:`. لا يتبنى هذا المسار؛ المطلوب في مشروعنا المحادثة أولًا، ثم تسجيل الاتصال والإشعار ومتابعة الدعم عبر API قبل فتح الاتصال.
- دخول القالب وFirebase Auth وGoogle/Apple login وآلياته ليست بديلًا لدخول مشروعنا وKYC وأدواره.
- ثيم القالب وخط Manrope ومتطلبات Dart أحدث من بيئتنا. ينقل التصميم بما يناسب Flutter 3.27.3 وNotoSansArabic وRTL، دون ترقية اعتمادات أو استيراد منظومة القالب كاملة.
- لوحة Laravel وموقع Next.js والاشتراكات والدفع مرجع فحص فقط؛ لا installer ولا MySQL ولا Backend بديل ولا ميزات مدفوعة ضمن هذه المرحلة.

المسارات الفعلية وربطها بالمراحل الخمس في `TEMPLATE_ADOPTION_MATRIX_AR.md`. يحتفظ سجل JSON ببصمات 21 ملف مصدر مختار لتثبيت المراجع المشار إليها.
