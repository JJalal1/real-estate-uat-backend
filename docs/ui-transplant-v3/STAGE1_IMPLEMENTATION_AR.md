اعتمد صاحب المشروع بدء خطة التلبيس في 11 أكتوبر 2026. هذه دفعة المرحلة الأولى على فرع `work/ui-transplant-v3-stage1` من تجهيز `4ae70b70712897f4da39c1662ea7c74938830cd5`، والأصل الحاكم `dc2805c9215dcd500fc7034effa953a4c3751761`.

## السلوك الناتج

- يبدأ الزائر والمستخدم والمعلن من Home جديدة: عنوان وهوية، مساحة تعريف، مدخل بحث، مداخل الخريطة والمفضلة والمقارنة، وعينة عقارات من بيانات الأصل. تبقى تسمية تبويب العقارات وترتيب بقية التبويبات كما في الأصل.
- البحث والخريطة يفتحان `/property-market` الموجودة دون تغيير محرك البحث أو فلاتره أو استعادة تاريخ البحث أو طلب الموقع.
- Home تستخدم `nearbyPropertiesProvider` و`PropertyMarker` الأصليين؛ تعرض صنعاء بوصفها النطاق الأولي الأصلي، ولا تدعي أن العينة أحدث العقارات أو كل اليمن أو موقع الهاتف. تتيح الخريطة متابعة الاستكشاف بحسب الموقع والفلاتر الأصلية.
- البطاقة تستخدم `display_price` الذي يحله النموذج الأصلي وتحفظ ملاحظة السعر؛ النقر يفتح `/properties/{id}`. لا اتصال مباشر أو آلية إعلان أو تواصل جديدة في Home.
- المفضلة والمقارنة والإشعارات تفتح مسارات الأصل المحمية بالدخول. يظهر مدخل إضافة عقار في مساحة المعلن فقط، ويفتح `/add-property` مع حاجز أهلية النشر الأصلي.
- تبقى مساحات الدعم والمدير ومدير المنصة وصفحاتها وصلاحياتها وترتيبها دون تغيير. التنقل يحتفظ بالتحميل الكسول وIndexedStack وسلوك الرجوع والخروج وتبديل الدور.
- تتعامل Home مع التحميل والفراغ والخطأ وإعادة المحاولة والتحديث بالسحب؛ تحديث بيانات الإعلان يظل مرتبطًا بـ`propertyDataRevisionProvider` داخل المزود الأصلي.
