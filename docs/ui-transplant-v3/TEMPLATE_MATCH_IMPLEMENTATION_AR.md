# تنفيذ تفاصيل التصميم من المصدر

هذه الدفعة تستكمل التصميم المنقول في #69، ولا تغير ملفات data/domain أو backend أو حساب الصلاحيات. مرجع المصدر الخاص هو eBroker 1.8.0 عند 425f019070db73253ff77181c77623d28225cc25، والآلية المجمدة هي Golden dc2805c9215dcd500fc7034effa953a4c3751761.

| عنصر المصدر | التنفيذ | تكييف بيانات المشروع |
|---|---|---|
| app_theme وtheme | PrimaryFont/Manrope، 087C7C، FAFAFA، 4D5454، الحدود وارتفاع النص | دلالات حالة المراجعة/التحذير الأصلية |

| AgentCard | غلاف 152، stack 198، avatar 70، badge 22، زوايا 16 | أسماء المعلنين والتحقق والتقييم الحقيقي من API الحالي؛ لا متابعين/باقات |

لا تنقل حزم Firebase/Hive/Cubit أو API القالب. لا تعرض بيانات مصطنعة داخل التطبيق؛ تستخدم البيانات المصطنعة في صور الاختبار فقط. أصول المصدر المنقولة عددها 140 وتتحقق آلياً بالبصمة.

يحافظ تصحيح اختبار المعاينة القديم على توقعاته الأخرى ويثبته guard حرفياً مقابل Golden. تضاف اختبارات لمسار بطاقة المفضلة، OTP، bounded/deduplicated/public advertiser data، وربط المعاينة بالمحادثة وصلاحيات الخادم، مع معاينات للشاشات الفعلية وتكبير النص. تسجل نتيجة التحليل/الاختبارات والبناء والـ commit في #69 بعد اكتمال CI.

نجاح CI يثبت قابلية البناء والقيود والفحوص المذكورة. لا يدعي تطابق كل بكسل لكل جهاز: الخط العربي نظامي، صور خادم القالب ليست ضمن الأرشيف، وبعض أقسام البيانات تستعمل شروط API الحقيقي. تبقى مقارنة القالب على جهاز Android مع بيانات متكافئة فحص القبول البصري.
