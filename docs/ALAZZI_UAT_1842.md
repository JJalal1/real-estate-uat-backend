# Alazzi UAT 1842

The owner approved the interface and broker messaging handoff PDFs on top of UAT 1841. The map uses the Home gradient for the selected property type. The Home assistant opens smart search for regular users. Verified brokers can choose search or listing preparation from the card. The broker directory cards are compact, and saved properties show a red heart.

The broker Messages destination lists conversations with follow-up status filters, actual last-message previews and unread counts. Linked listings, classification and private follow-up controls are available from the conversation. Typing presence is scoped to participants, expires quickly and never contains draft text. The message surfaces use the system appearance and support the Android navigation inset in both themes.
