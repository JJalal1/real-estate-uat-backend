- الأساس المختبر: `cc9e11a8713aa971da761dde286073473fc06786`، CI457، APK1457.

- يبنى APK جديد مطابق لكود المنتج وبصمة جديدة؛ لا ينسب إلى بايتات APK1457. رقم أول جولة1458 ثم `1457 + رقم تشغيل workflow الجديد`، وليس رقم Broker CI.

## الأدلة الجديدة المطلوبة

1. بحث عربي فعلي ونتيجة موجودة، شقة/إيجار، استبعادها عند اختيار البيع، ثم الدخول بنقرة بطاقة.
2. أربع أحداث لمس من عملية واحدة بفاصل80ms، مع توقيت الإرسال والعودة؛ صور التكبير والرجوع، وإيماءة حقيقية بإصبعين للتكبير والتصغير. لا تكفي عودة أداة اللمس بالنجاح.
3. مسح استعلام الخريطة بالزر الموجود أو فعل التحرير الأصلي المتاح للأداة، ثم «تنفيذ»، وثبات الفلاتر وعدم اختيار فلل، وعقارات/علامات فعلية، وتحريك الخريطة ونتيجة مستقرة محدثة. تغير عداد مؤقت إلى صفر لا يكفي.
4. اختيار مسار الذكاء الاصطناعي المتاح وتوثيق البوابة الفعلية. المصدر لا يثبت بوابة اشتراك؛ لا شراء ولا ادعاء نجاح المزود من استجابة fallback.
5. عطل اتصال مضبوط داخل محاكي API36 التجريبي فقط، ثم إزالة الحجب وإعادة المحاولة بالنقر. تفصل هذه التجربة عن مهلة الخادم الطبيعية وعن طلبات الفحص من المضيف.

أداة الإدخال APK مؤقت مستقل، يستهدف نفسه ولا يفتح Activity أو يوقف عملية التطبيق الأصلية. يستخدم واجهات Android العامة دون منح صلاحيات دائمة أو قراءة جلسات. تزال حزمتا التطبيق وأداة الإدخال بعد الجمع. APK وملفات المفاتيح وXML والسجلات الخام لا ترفع ضمن الأدلة؛ المسموح JSON محدود وPNG أصلية وMP4 أصلي.

## عائق الدخول الحالي

اختيار أي حساب UAT مناسب مصرح به. كلمات مرور الحسابات المزروعة عشوائية، والدخول في الواجهة يستخدم OTP. تعريف رمز اختبار وأرقام مسموحة في Blueprint لا يثبت الإعداد الفعلي أو يوفر السر. يلزم مسار دخول معتمد متاح إلى الحسابات القائمة، دون تجاوز OTP أو استخراج جلسة مالك أو إصدار token مباشرة أو تغيير دور أو تفعيل وصول جديد.

لذلك تبقى رحلات الدخول والمسودة والصور والإرسال والدعم والصلاحيات المتبادلة محجوبة إلى أن يتاح الدخول العادي. لا تحول اختبارات الكود أو وجود الحسابات إلى قبول لهذه الرحلات.

تسليم الجولة: تقرير قبول محدث مع نسخة/مصدر/بصمة APK وخادم، وجدول PASS/FAIL/BLOCKED/NOT RUN، وتحليل اللقطات والفيديو، وحزمة أصلية قابلة للتنزيل. لا إغلاق للمرحلة الأولى إذا بقي مانع قبول. لا Production أو متاجر أو شراء أو نسخ احتياطي أو استعادة نظام.
