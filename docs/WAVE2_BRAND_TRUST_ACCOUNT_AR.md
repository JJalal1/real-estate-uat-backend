## جرد الموجود وحدود التنفيذ

موجود: مشتقات صور خاصة من الدفعة الأولى، معرض/تكبير، قوائم API بصفحات، PropertyAsset وكشف التكرار المؤكد/المشتبه، بلاغات SupportCase ومراجعة بشرية وطابور مهام موحد، وبلاغ المحادثة ذي وصول خاص مدقق. لا علاقة حظر حساب-حساب حاليًا، ولا مسار طلب حذف حساب مخصص. لا مزود فحص صور دلالي موجود معتمد؛ لا تفترض هذه الدفعة أن أبعاد الصورة أو لونها يثبتان صلتها بالعقار.

يحافظ اسم العرض على package/applicationId/روابط/مفاتيح التخزين والتوقيع وفق نظام البناء القائم. الاسم على الجهاز «عقار»، والاسم المرجعي للمتجر «عقار | Aqer عقارات اليمن». لا إنشاء حساب متجر أو نشر. الدخول إلى حساب موجود يبقى دون اسم؛ الاسم في التسجيل فقط، كما يقتضي تصحيح المالك السابق.

## التنفيذ في الفرع

- الحظر: جدول علاقة شخصية وحيد `user_messaging_blocks` بمفتاح فريد واتجاه عكسي مفهرس وRLS ومنع وصول Data API المباشر. Laravel يوقف الرسائل الجديدة وفتح محادثة أو اتصال جديد في الاتجاهين؛ يبقى التاريخ والبلاغ وإيصال رسالة قديمة مؤكدة متاحًا. إلغاء الحظر يزيل علاقة صاحب الطلب فقط. أقفال أزواج متناسقة قبل أقفال المستخدم تمنع تعارض العملية مع إنشاء محادثة دلال. لا حظر حساب إداري أو صلاحية جديدة.
- البلاغ: قفل المستخدم يحسم تكرار الطلب؛ 409 خاص بالبلاغ المتكرر يعيد المرجع الحقيقي لصاحبه. Flutter يعرض رقم المتابعة بعد التأكيد فقط، ويربط بلاغ الإعلان بمركز الدعم. لا إخفاء تلقائي لإعلان بسبب بلاغ واحد أو كشف المبلغ للمعلن.
- حذف الحساب: الطلب غير التدميري يستخدم SupportCase/SupportTask الحاليين مع تأكيد وحالة ورقم متابعة. لا تغيير لجلسات الحساب أو بياناته. جرد العلاقات والسياسة المؤجلة في `WAVE2_ACCOUNT_DATA_RETENTION_AR.md`.
- صلة الصور: مراجعة بشرية لكل صورة في ListingReview ذاته، بقرار مرتبط/يحتاج توضيحًا/غير مرتبط وسبب وسجل تدقيق. التكرار المطابق لنفس مرجع الملف والقرار لا ينشئ مراجعات مكررة؛ استبدال الملف يبطل النتيجة السابقة. لا مزود آلي معتمد موجود ولا مشاركة صور أو تصنيف مبني على اللون/المساحة. نتائج المراجعة لا تنشر أو ترفض أو تحذف تلقائيًا.
- الهوية: ادعاءات PropertyAsset المطابقة والتمثيل النشط تبقى حواجز صريحة. التشابه المكاني/العنوان/المساحة وحده للمنزل المستقل أصبح اشتباهًا للمراجعة؛ تأكيده يتطلب أيضًا مرجع بيت صريحًا مطابقًا وعنوانًا مقاربًا جدًا. تمييز الوحدات وحدود الأراضي ومبررات الدعم وسجل التدقيق الحالي محفوظ.
- العرض: استخدام card/detail/gallery/zoom القائمة، مصغرات التفاصيل والمفضلة تختار card؛ المعرض والتكبير يحتفظان بنسختيهما. ذاكرة صور العرض المؤقتة محدودة18 عنصرًا/24MiB وصلاحية دقيقتين، تجمع الطلبات المتزامنة وتزيل الفشل وتُمسح عند تبديل الحساب؛ لا ملفات قرص ولا نسخ أصول خاصة ولا حزمة جديدة. قوائم الأقسام تستخدم builder قرب العرض مع حماية طلب المزيد وتحديث إحداثيات القسم القريب.
- العلامة المائية: مسار GD محلي غير مفعل، ببصمة أصل متجهي معتمد وإصدار مشتقات مستقل وروابط إصدار عند التفعيل. تكرار أبيض قطري10% وختم زاوية24% دون معرف إعلان؛ لا إعادة ضغط للأصل ولا توليد عند عرض مشتق مخزن. أصل الإنتاج غير مرفق أو معتمد في الفرع، والتفعيل بدونه يفشل بوضوح. اختبارات المسار تستخدم مضلعًا اصطناعيًا لا يمثل شعار عقار. أصول الشعار/البداية/أيقونة الجهاز النهائية ومعاينتها الهندسية تبقى قبل اعتماد المالك، ولا يُقدّم رمز القالب المؤقت كشعار جديد مطابق.
- الاسم والواجهة: اسم الجهاز وMaterialApp «عقار»، والدخول فاتح/نعناعي بالنص الكحلي والأفعال التركوازية وحقول Flutter حقيقية، مع بقاء الدخول بلا اسم والتسجيل باسم. لم تتغير حزمة التطبيق أو مفاتيح الحسابات أو الروابط أو سياسة التوقيع.

توافق API إضافي: can_send/blocked_by_me في المحادثة، relevance_review في صور واجهة المراجعة، endpoints الأمان والمراجعة الجديدة، واستجابة تكرار البلاغ ذات المرجع؛ العقود الأصلية باقية. معاملات variant/v اختيارية ولا تكشف الأصل. جدول الحظر والعقود الجديدة مقترحات PR للمراجعة قبل اعتماد ترحيلها؛ لا اعتمادية أو خدمة أو بروتوكول رفع جديد.

## نتائج قابلة للإثبات وحدودها

في أول checkpoint فقط، تشغيل `39585102154` على المصدر `e92b6e5eed89c148e883a41a0459b43b4178fafa` نجح23 اختبارًا وفشل اختبارًا واحدًا لتداخل حدود الطلبات (276 assertion إجمالًا). فُصلت prefixes الحظر/البلاغ/حذف الحساب/الإرسال بعد ذلك. لا تنسب هذه النتيجة للمصدر الأحدث أو لاختبارات الصور الجديدة؛ لم يظهر تشغيل لاحق له حتى آخر تحقق.

نجح محليًا فحص مطابقة المخطط القانوني للمصدر، و6 اختبارات حارس قفل الاعتماديات، و7 اختبارات حارس تحليل المصدر، و4 اختبارات حارس أصول القالب، و`git diff --check`. هذه17 اختبارات Python للحراس، وليست تشغيل Flutter analyze أو Laravel أو بناء APK. PHP/Flutter غير متاحين محليًا. فتح صفحة Actions في المتصفح المتاح مُنع بواسطة قيود الاتصال، وأداة GitHub المتاحة لا تعرض بدء workflow جديد. لذلك يبقى PR Draft والقبول الآلي والبناء والمقارنة البصرية وملف التنزيل الجديد OPEN؛ لا نعيد تسمية APK1113 القديم كأنه نتيجة هذه الدفعة.

أضيفت اختبارات Laravel لمرجع بلاغ مكرر، الحظر في الاتجاهين وإلغائه المتبادل والتاريخ وإيصال قديم وحدود الطلب، طلب حذف لا يمس بيانات الحساب، مراجعة صورة بصلاحيات الاستلام وبصمة الملف وتكرار آمن واستبدال متأخر، عدم تأكيد منزل بسبب شارع متشابه، أصل خاص/EXIF/دوران ومشتقات مخزنة ومسار علامة معطّل دون اعتماد. واختبارات PostgreSQL للـRLS والمنح والقيود وإعادة migration المؤقتة. اختبارات Flutter الجديدة تغطي حالات الحذف والحظر والفشل والتأكيد والخط1.0/2.4، إيصال البلاغ، الذاكرة المحدودة وTTL وتبديل الجلسة والطلبات المتأخرة وصحة عنوان صورة المراجعة. جميع الاختبارات الجديدة مضافة لكنها غير مثبتة التشغيل بعد.

حارس جلسة العملية يمنع إرسال رسالة أو بلاغ أو مراجعة قديمة باسم حساب تبدّل أثناء قراءة الرمز؛ قرار الصورة يحمل token لبصمة الملف المعروض ويرفضه الخادم إذا استبدل الملف. عارض صور المراجعة يحتفظ بالطلب داخل عمر الودجت، يتيح إعادة المحاولة وينهيه خلال25 ثانية، ولا يرسل authorization إلى أصل خارجي أو مسار إداري آخر. ذاكرة بايتات صور الإعلان18 عنصرًا/24MiB فقط؛ ذاكرة فك الصور تظل تحت ImageCache الحالية. لا حفظ قرص أو بنية تخزين جديدة.

النسخ الداخلية الجديدة تمر بمسار التعقيم. روابط `cdn_url` التاريخية الخارجية تبقى طبقة توافق قائمة؛ لم ننقل صورها إلى مزود جديد أو نفترض إثبات خلو مصدر خارجي من EXIF. أي توحيد لاحق لها يحتاج جردًا ومصدرًا مسموحًا وخطة انتقال، دون جلب عناوين غير موثوقة أو كشف أصول خاصة.

لا توجد حاجة مالية جديدة: GD والتخزين الخاص والطابور والمراجعة البشرية وذاكرة Flutter الحالية تكفي للمسار الحالي. فحص دلالي آلي مستقبلًا يحتاج اختيار مزود/قدرة محلية ومراجعة خصوصية/تكلفة وموافقة منفصلة؛ لا مزود أو فاتورة مفعلة هنا. اعتماد متجه الشعار/الهوية وأصول البداية والأيقونة وتفعيل العلامة، الحذف النهائي ومدد الاحتفاظ، وتجربة الهاتف تبقى قرارات/بوابات منفصلة محددة في المرجع.
