# جرد بيانات الحساب وطلب الحذف — مقترح للمراجعة

هذه وثيقة تنفيذية لجرد العلاقات الحالية، وليست سياسة احتفاظ قانونية معتمدة. لا تُحدد الدفعة مددًا اعتباطية ولا تنفذ حذفًا نهائيًا. مسار `POST /api/account/deletion-request` ينشئ SupportCase وSupportTask في الطابور الحالي بعد تأكيد المستخدم؛ تكرار الطلب المفتوح يعيد المرجع نفسه. حالة `resolved` تعني مراجعة الطلب، ولا تعني حذف الحساب. لا تُلغى جلسة أو يُحظر نشر حساب بمجرد إرسال الطلب.

| البيانات الحالية | العلاقات/المخزن | التصرف المقترح عند اعتماد حذف نهائي مستقبلًا | المدة الحالية لهذا المشروع |
| --- | --- | --- | --- |
| الهوية ووسائل الاتصال | users، أدوار/صلاحيات الحساب وملفه | إزالة/إخفاء بيانات التعريف بعد تسوية الحقوق مع إبقاء المعرف اللازم للسجلات المحمية؛ لا حذف شامل بـcascade | لم يعتمد المالك مدة؛ لا مهمة تنظيف جديدة |
| الجلسات والتحقق | api_tokens، verification_challenges، password_reset_tokens | إبطال الجلسات والرموز عند إتمام الحذف المعتمد ومنع إعادة الدخول والنشر؛ طلب المراجعة وحده لا يبطلها | تبقى مدد الانتهاء التقنية القائمة دون تغيير؛ سياسة الحذف النهائي غير معتمدة |
| الإعلانات وهوية العقار | properties، property_assets، property_representation_claims، property_publication_blocks، property_identity_checks | مراجعة إخفاء إعلانات الحساب وإنهاء تمثيله مع حفظ هوية العقار ومنع إفساد إعلان أو حق لطرف آخر | غير معتمد؛ لا تغيير نشر أو تمثيل في هذه الدفعة |
| الصور والمستندات | property_images، listing_documents، listing-originals/، editor-drafts/، listing-display/، مخزن إثباتات خاص | حذف الملفات غير المشار إليها فقط بعد فحص جميع المراجع وحقوق الاحتفاظ؛ الأصل المشترك لا يُحذف لمجرد حذف صف أو حساب | غير معتمد؛ نسخ العلامة المائية القديمة تظل خاصة حتى خطة تنظيف معتمدة |
| المسودات على الخادم والهاتف | listing_editor_drafts، آلية ListingRecoveryStore الحالية | إزالة مسودات المستخدم وملفاتها المنفصلة بعد حفظ العمل/القرار المعتمد؛ فصل الحسابات يبقى مفروضًا | لا نظام مسودات أو تخزين بديل؛ سياسة المسح النهائي غير معتمدة |
| الرسائل والمشاركون والحظر | message_threads، message_thread_participants، private_messages، user_messaging_blocks | إخفاء/تقليل الهوية وفق حقوق الطرف الآخر والبلاغ؛ لا مسح محادثة مشتركة أو التفاف على التدقيق | غير معتمد؛ الحظر يمنع الجديد ويحفظ التاريخ |
| البلاغ والدعم وسجلات الوصول | support_cases/messages/events، support_tasks/events، conversation_reports، private_message_access_events، audit_logs، listing_reviews | حفظ السجل المطلوب لحقوق الأطراف ومراجعة تقليل الهوية دون تعديل journal غير قابل للتغيير؛ الوصول مقيد بالسياق والصلاحيات القائمة | غير معتمد؛ لا كسر للسجلات غير القابلة للتعديل |
| المفضلة والبحث والتفضيلات | property_favorites، saved_property_searches، user_notification_preferences، user_notifications | تنظيف روابط المستخدم الخاصة بعد القرار المعتمد دون المساس بملكية الإعلان الأصلي | غير معتمد |
| المحتوى والتقييم | listing_comments، advertiser_ratings، property_listing_views | مراجعة الإخفاء/تقليل التعريف مع بقاء حقوق الأطراف والتوثيق | غير معتمد |
| التحقق المهني والمستندات | account_verification_profiles/documents، broker_verification_documents، listing_broker_verifications | احتفاظ مقيد أو إزالة آمنة وفق السياسة المعتمدة؛ عدم إتاحتها للعامة | غير معتمد |
| الاتفاقات والسعي والحقوق المالية | property_agreements/revisions/acceptances، property_sai_terms/attestations/settlements، property_deal_financial_terms | الإبقاء على التاريخ والالتزامات والسندات المحمية مع مراجعة تقليل التعريف مستقبلًا | القرار المالي والقانوني مطلوب؛ لا تغييرات في هذه الدفعة |
| الدفعات والدفتر والمستحقات والنزاعات | property_payments/allocations/payment_methods، property_manual_payment_confirmations، property_platform_receivables، property_payouts، property_refunds، property_financial_ledger_entries/lines، property_financial_holds/disputes، payment_events | لا تعديل أو حذف للدفتر أو إعادة حساب؛ مراجعة مستقلة قبل أي تقليل تعريفي | غير معتمد؛ القواعد والسجلات الأصلية محفوظة |
| النسخ الاحتياطية وسجلات التشغيل | البنية الحالية لمقدمي التخزين/قاعدة البيانات | سياسة دورة النسخ الاحتياطي والتخلص منها تحتاج اعتمادًا ومراجعة قدرات المزود الحالي | لم تتحقق الدفعة من مدد مزود حي، ولا تدعي محوها |

قبل تفعيل تنفيذ نهائي: يعتمد المالك السياسة ومدد كل فئة ومعالجة الحقوق القائمة؛ تُراجع العلاقات ذات restrictOnDelete والسجلات غير القابلة للتغيير؛ تُنفذ تجربة مؤقتة ونسخ استعادة وفحص مراجع الملفات؛ ثم تُختبر نهاية الجلسات ومنع الدخول/النشر وحماية الطرف الآخر. كل ذلك خارج تفعيل هذه الدفعة، ولا توجد وظيفة مجدولة أو endpoint ينفذ حذفًا فعليًا الآن.
