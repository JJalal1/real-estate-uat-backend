## التنفيذ

- عقد اختياري `ranked_search=1` على `/properties`، ونفس الصفحات/الصفوف عند طلبه من `/properties/nearby`. المستهلك القديم يحتفظ بعقد2 والترشيح الصارم. الرأس `X-Aqer-Ranked-Contract: 1` يمنع عميل الرابعة من قبول خادم يتجاهل الترتيب.
- نتائج المطابقة كاملة أولًا عبر الصفحات ثم حد أقصى12 بديلًا مفسرًا. التعادل ثابت بمعرف العقار. بديل لا يصبح مطابقًا لأن النص عُدّل تخمينيًا.
- الأسماء الدقيقة/الإنجليزية والمرادفات الموثقة تأتي من سجل الأماكن النشطة الحالي. إعداد `discovery_ranked.place_aliases` اختياري، ولا تضاف أسماء محلية مخترعة. تطابق اسمين في مدينتين يحتاج سياق المحافظة ولا يختار تلقائيًا أحدهما. خطأ وحيد الحروف بثقة كافية يبقى «قريبًا»؛ الاسم الصحيح الموجود يفوز قبل التخمين.
- تخفيف السعر أو المساحة محصور20%، والغرف/الحمامات بفارق1؛ بحد أقصى مجموعتي اختلاف. الغرض والعملة والنوع والنشر وصلاحيات العرض والقيود الأخرى تبقى صارمة. الإيجار الشهري يفرض rent. تعارض غرض النص مع الفلتر يعرض رسالة تصحيح ولا يتجاهل شرطًا بصمت.
- ترتيب البدائل المعلن: أقل عدد شروط مختلفة، ثم داخل الميزانية قبل تجاوزها، ثم المسافة إلى حدود المنطقة، ثم مقدار فرق الفلاتر النسبي، ثم ID. القرب لا يعني السعر وحده. إذا لا يوجد مرجع مكاني موثق، لا يخفف النص إلى مخزون عشوائي.
- البديل الجغرافي لا يتجاوز5كم عن حدود الرسم/المنطقة المسجلة أو الدائرة المطلوبة. SQL الإنتاج يستخدم `ST_DWithin` قبل المسافة والترتيب. لا تغيير فهرس أو خدمة؛ مسار SQLite اختبار تقريبي منفصل.
- جلسة البحث القديمة والإلغاء وحراسة تغيير الحساب باقية. القائمة وخريطة البحث تستخدمان `DiscoveryMatch` نفسه. علامة≈ وشرح الفرق والمسافة يميزان البديل، والتجمعات لا تخلط تصنيفين، واختيار بديل لا يقدمه على المطابقات.
- لا تشغيل بدائل عند فشل الشبكة؛ الاستجابة الفاشلة تظل خطأ/محاولة. التفعيل في مرشح الرابعة فقط عبر `AQER_RANKED_DISCOVERY=true`، والافتراضي OFF حتى نشر عقد الخادم الجديد. خريطة الاستكشاف العامة ذات nearby القديم تحتفظ بنطاقها؛ لا ننسب إليها قبول عقد البحث المشترك.

بحث ← فلاتر ← أكثر من صفحة مطابقات ← رسم ← فتح عقار ← رجوع مع نفس الحالة ← تغيير البحث/الشروط ← بدائل مفسرة ← لا بديل مناسب ← انقطاع منفصل ومحاولة. الحالات الهندسية مضافة إلى الرحلة: حد الرسم، حيّان باسم واحد، وحدتان في نقطة واحدة، ورد متأخر بعد تغيير الفلتر. لا تعاد الجولات المقبولة كليًا.
