# قبول الردود المتأخرة في المرحلة23

هذا هدف Android تجريبي منفصل `lib/phase23_native_callback_main.dart`، وليس ملف تثبيت مقترحًا للمالك. يبقى `main.dart` العادي مستقلًا عنه. يلزم تفعيل العلم الصريح وبيئة UAT وعنوان API المثبت؛ خلاف ذلك يتوقف الهدف. لا تتغير المصادقة أو الصلاحيات أو TLS أو التخزين أو حدود الشبكة. يمنع اعتراض Dio كل كتابة أعمال إلى الخادم، بما فيها حذف الحساب أو حفظ المسودة أو قراءة الإشعار، قبل الإرسال. الاستثناء الوحيد هو POST للهاتف start/verify/logout على عنوان UAT المثبت. يوقف كذلك طلبات AI المدفوعة.

يُستخدم الدخول العادي بالهاتف للحساب الاصطناعي66 ثم26. يحجز الهدف اكتمال AI ونتائج البحث ونقطة GPS الاصطناعية، ويستدعي وحدات البحث والمحرر الحقيقية. لا يغيّر هوية المستخدم أو حقبة الجلسة يدويًا. تكتمل الاستجابات القديمة فقط بعد اكتمال دخول26 وحفظ لقطة حالته الجديدة مرة واحدة.

يجب أن يثبت الدليل ترتيب الالتقاط ثم الدخول البديل ثم اللقطة ثم إطلاق الرد ثم اكتماله؛ وأن تختلف حقبة الالتقاط عن حقبة الحساب البديل. تقارن جميع حقول حالة البحث قبل/بعد، ويثبت إلغاء النقل مع إكماله عمدًا رغم الإلغاء، ومنع استدعاء بحث تابع للرد القديم. في GPS يشغّل المستخدم زر الموقع في محرر66 ثم يتجاهل التقدم ويخرج عاديًا، ويفتح محرر26 بنقطة فارغة. بعد إطلاق الرد تبقى نقطة26 فارغة وتبقى نسختا التخزين المحلي الفعليتان فارغتين. لا يثبت هذا تشغيل مزود GPS أو AI الخارجي أو جهاز فعلي.

تُصدر الأداة حالات ثابتة وحقولًا رقمية محدودة فقط، ويرفض جامع الأدلة أي نص أو مفتاح إضافي. لا تصدّر صور الشاشات الخاصة؛ لا أرقام هواتف ولا OTP ولا توكنات ولا محتوى وثائق. يحتوي إيصال APK على علامتي التجربة والقراءة فقط، ويُتحقق من وجودها في ملفات libapp.so الثلاثة؛ لا يسمح APK عادي بتصدير تسميات الأداة.

المهمة `.github/workflows/phase23-native-callbacks.yml` لا تبدأ الجهاز إلا برسالة `[run-callbacks]`. تُنشر تغييرات المصدر أولًا عبر `[collector-only]` وتراجع بوابات المصدر، ثم يبدأ جهاز واحد. النسخة1605 بهوية UAT وتوقيع مؤقت؛ لا توافق تحديث مفترض مع تثبيت المالك. هذه الجولة للردود المتأخرة والقراءات فقط. يمنع المنفذ ضغط الحذف أو الحفظ أو قراءة الإشعارات، ويمنع set وعمليات البيانات، ويقصر الدخول على الحسابين66 و26. تبقى41 إشعارًا اصطناعيًا وحذف66 متوقفين بعد رفض المراجعة الآلية للجولة السابقة؛ يتطلبان موافقة صريحة منفصلة. لم تنشأ أي إشعارات ولم يحذف الحساب. لا نشر إعلان ولا تبديل أدوار ولا تغيير مورد مدفوع أو Production.

نتائج التنفيذ تضاف إلى السجل الرئيسي بالأرقام والهوية الحقيقية للمهمة بعد مشاهدة الأدلة؛ تجهيز الأداة ونجاح CI وحدهما لا يغلقان قبول Android.
