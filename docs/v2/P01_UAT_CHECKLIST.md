# V2 P01 — Team UAT checklist

Use the APK as a normal first-time user. Record only what you actually experience.

## Entry and account

- Open the app as a guest.
- Confirm the first screen is understandable without explanation.
- Start account entry using a WhatsApp number.
- Test an invalid phone value.
- Request a code, enter a wrong code, then enter a valid code.
- Test resend.
- For a new account, complete the four-part name.
- Close/reopen the app and confirm the session behavior is understandable.
- Open the profile and review name/phone editing.
- Log out and log in again.

## Publishing identity

From Account, test each path separately where UAT accounts permit it:

- Owner.
- Dalal.
- Real-estate office.
- Required/optional document labels.
- Selfie capture behavior.
- Governorate/district selection.
- Validation messages.
- Submit for review.
- Pending state.
- Support review.
- Approved / needs-more-info / rejected states.

## Experience review

For every screen answer:

- Is the main action obvious?
- Is any text unnecessary?
- Is anything important hidden?
- Is the Arabic easy to understand?
- Is the font comfortable?
- Are colors professional and calm?
- Is spacing comfortable?
- Is navigation predictable?
- Does the screen feel crowded?
- Is there any feature shown before it is needed?
- Would a first-time Yemeni user understand it without training?

## Feedback format

For each note provide:

- Screen.
- What you tried.
- What happened.
- What you expected.
- Severity: blocking / important / improvement.
- Screenshot if visual.

P01 remains open until blocking feedback is resolved and the owner accepts the package.
