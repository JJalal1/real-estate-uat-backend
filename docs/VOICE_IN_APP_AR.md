## تجربة المستخدم

الضغط على الميكروفون يغلق لوحة المفاتيح ويهيئ الالتقاط. عند جاهزية الخدمة يظهر «نستمع إليك الآن»، مايك بنبض هادئ وموجة تتفاعل مع مستوى الصوت. النص الجزئي يظهر داخل السيكشن ولا يذهب إلى Gemini. عند انتهاء الكلام تظهر مرحلة تجهيز النص، ثم يعود السيكشن إلى حالته الطبيعية ويحلل النص النهائي فقط. يوجد إلغاء، وإنهاء مبكر للكلام؛ يحترم التصميم تقليل الحركة وحجم النص وRTL.

الرئيسية لا تنتقل تلقائيًا إلى شاشة البحث. تظهر الشروط الحقيقية والنتائج من API نفسه داخل سيكشنها، مع رابط صريح لعرض كل النتائج والفلاتر. النص والصوت والتعديل اليدوي يستخدمون SmartSearchSession نفسها. مثال «خلي السعر من خمسين إلى مئة ألف» يضيف حدّي الإيجار الشهري ويحافظ على الشقة والإيجار وصنعاء وثلاث غرف. لا يبدأ الصوت جلسة جديدة ولا يكتب الفلاتر مباشرة؛ Laravel يبقى مسؤولًا عن تفسير التغييرات المسموحة.

الإلغاء يعيد المسودة المكتوبة ولا يرسل النص الجزئي أو النهائي المتأخر. تبديل الشروط أو بدء بحث جديد أو مغادرة المسار يوقف الالتقاط ويبطل الرد القديم. إغلاق التطبيق يوقف المايك؛ الالتقاط محدود بمدة ويتوقف بعد انتهاء الكلام. رفض الإذن، الصمت أو تعذر الخدمة/الاتصال يعيد الكتابة مع رسالة داخل السيكشن ويحافظ على الجلسة والنتائج.

## النطاق التقني

- معالج Native منفصل عن الكاميرا والتخزين الآمن؛ MainActivity يمرر فقط دورة الحياة ونتيجة إذن الميكروفون.
- RECORD_AUDIO يطلب عند أول استخدام فقط، مع إعلان RecognitionService لدعم Android 11+. شاشة إذن Android الأولى لازمة لاستخدام الميكروفون؛ لا واجهة Google للتفريغ ولا نافذة صوت داخل التطبيق.
- لكل التقاط معرف مستقل، وتجاهل للأحداث من التقاط ملغى/أقدم أو تابع لمستهلك آخر. الإنهاء والموارد وحدود الوقت تحت تحكم التطبيق.
- لا ملفات صوت، ولا سجل للنصوص/PCM، ولا خدمة خلفية، ولا TTS، ولا حزمة Flutter أو تغيير Gradle/pubspec. خدمة التعرف التي يوفرها الجهاز قد تعتمد على الشبكة؛ لا ادعاء أنها دائمًا تعمل محليًا أو دون اتصال.
- مساعد وصف الإعلان يستخدم معالج الصوت نفسه داخل نموذج المراجعة، ويبقى التطبيق اليدوي للاقتراح مطلوبًا. لا تغيير API أو قواعد صلاحية/مالية أو قاعدة بيانات، ولا حاجة لنشر Laravel لهذه المهمة.
