# استكمال القوائم الخاصة في المرحلة23

هدف UAT منفصل للقراءة فقط يستخدم الشاشات والمستودعات والمصادقة والصلاحيات الحقيقية. لا يستورده main.dart ولا يعد ملف تثبيت للمالك. يمنع النقل كل كتابة أعمال وطلبات AI قبل الإرسال، ويستثني الدخول والخروج العاديين على مضيف UAT المثبت فقط. لا تسجيل دخول للحساب المحذوف أو إنشاء حسابات أو رسائل أو تعديل بيانات.

أحجام الطلب المعلنة: عقاراتي والتوفر10، المفضلة والرسائل وبلاغات المحادثات1، مهام الدعم والتحقق وحالات الدعم ومراجعة الإعلانات2. تتغير per_page فقط للأسطح الداعمة لها؛ page والفلاتر والاستجابة تبقى حقيقية. العملاء يحتفظ بعقد30 الثابت في الخادم. قبول هذه الجولة يخص تكامل صفحات UAT الأصغر؛ عقود الحجم الأصلي واختباراتها منفصلة، ولا يصنع الهدف صفحات أو فراغًا أو نجاحًا مزيفًا.

القراءة الرقمية تسجل بدء الطلب ونجاحه أو خطأه، حجم الطلب الأصلي والفعلي، الصفحة وعدد الصفوف ونهاية الصفحات والتكرار وحقبة الجلسة. لا تسجل عنوان الطلب أو الفلاتر أو معرفات الصفوف أو محتواها. تصدير الشاشة الخاصة مقصور على تسميات ثابتة ومخطط رقمي مغلق؛ لا صور أو فيديو أو وثائق أو وارد خاص في الحزمة. انتظار النصوص الساكنة لا يتطلب enabled، مع بقاء حراسة enabled والشاهد للضغط والإدخال.

تنشر الأداة مع collector-only وتراجع الاختبارات أولًا، ثم تشغيل واحد بعلامة run-private-pages. يمر كل دور بالخطأ والمحاولة والصفحات والنهاية والفراغ الممكن فعليًا، مع الثيمين والتكبير ضمن النطاق المتاح. البيانات السابقة لا تكتب لتكبير القوائم. ما لا يتجاوز حجم الصفحة يبقى محدود الدليل. لا تعمم سلامة التدفق الرقمي على قبول بصري لكل شاشة أو هاتف فعلي.

تظل أدلة الجولات السابقة معتمدة، والمؤجلات المالية وTUS والفيديو وحدود الجهاز والتوقيع والمزودات محفوظة. لا نشر Backend أو دمج أو Production. تسجل نتيجة الجولة بعد مشاهدة الأدلة وتنظيف جلساتها، وليس من نجاح البناء وحده.
