# اختبار اعتماد HTTP المتزامن على PostgreSQL المحلي

مرجع العمل قبل هذا الاختبار: `87ecd5f706c36e0678a7fe887cfba1ece6b89eed`. استخدمنا قاعدة PostgreSQL 17.11 وPostGIS 3.6.2 محلية مستقلة، مع ترحيلات Laravel الـ59 وبيانات وحسابات وصور اصطناعية فقط. لا اتصال بخادم UAT ولا مزود AI.

## حدود الطلب الفعلية

أنشأ الاختبار عمليتَي PHP مستقلتين، لكل منهما اتصال قاعدة بيانات وLaravel HTTP kernel مستقل. مرّت طلبات `POST /api/admin/listing-review/listings/{id}/approve` بالمصادقة بالرمز الاصطناعي، وmiddleware صلاحية `listings.moderate`، و`ListingReviewController`، ثم `ListingWorkflowService::approve`. أثبت طلب مالك الإعلان `403` وطلب بلا رمز `401`. راجع الدعم الصور لكل إعلان عبر endpoint مراجعة الوسائط قبل الاعتماد.

أمسك المنسق قفل الأصل أو جدول التمثيل، ثم أطلق العمليتين معًا ولم يرفع القفل قبل رؤية اتصالَي PostgreSQL ينتظران `Lock` في `pg_stat_activity`. بذلك لم يكن الاستدعاءان متتابعين.

## النتيجة

| الرحلة | النتيجة |
| --- | --- |
| اعتماد إعلانين قيد المراجعة لنفس الأصل في الوقت نفسه | `409/409` من حارس الهوية برسالة «لا يمكن اعتماد الإعلان لأنه يطابق عقاراً أو وحدة مسجلة بالفعل.»؛ صفر إعلان منشور وصفر قيد تمثيل نشط في هذه النقطة. لم نغيّر قاعدة الهوية كي نفرض فائزًا مصطنعًا. |
| قرار الدعم اللاحق | أعاد الدعم الإعلان المنافس للتصحيح، فخرج من حالات الهوية المرشحة. أعاد مسار الاعتماد تقييم الإعلان الصحيح، فنجح `200` ونُشر إعلان واحد وأنشئ قيد نشط واحد للأصل. |
| اعتماد وحدتين مختلفتين بالدور والمبنى نفسيهما | كانت هوية كل وحدة `distinct`. نجح طلبا الاعتماد المتزامنان `200/200`، ونُشرت الوحدتان بقيدي تمثيل مستقلين. |

نتيجة PHPUnit: `1/1` مع `67` تأكيدًا. الحالة النهائية في قاعدة الاختبار قبل تنظيفها: 3 إعلانات منشورة، 3 قيود تمثيل نشطة، و3 أحداث اعتماد. Receipt محلي غير مرفوع: `local-toolchain/identity-http-approval-receipt.json`، SHA256 ‏`6A55F163193479D4F172E0B06817A06BAA24EEA13C149C598D7B83D646BBF202`. يوثق معرفَي اتصال وانتظار القفل ونتائج HTTP لكل سباق دون أسرار.

اختبار HTTP kernel يمر بطبقات Laravel المذكورة، لكنه لا يختبر خادمي ويب منفصلين أو الشبكة الخارجية أو جهاز المالك. لا تغيير لقواعد التمثيل أو المخطط. حُذفت قاعدة الاختبار المستقلة والوسائط الوهمية بعد قراءة الدليل، وتوقف PostgreSQL المحلي. الرجوع عن كود الاختبار يكون بترك commit المحلي اللاحق.
