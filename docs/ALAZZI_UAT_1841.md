## Alazzi UAT 1841

The regular marketplace Categories tab opens rent or sale, then property type. Messages shows the aggregate unread message count. The bell shows unread platform notifications.

Home uses the logo gradient on the selected property type, closer section spacing, sale or rent at the upper left of each listing photo, and the original comparison action below the facts. Listing age uses the optional publication timestamp and is capped at six months. Verified personal owners who already use their listing slot see the upgrade prompt first.
