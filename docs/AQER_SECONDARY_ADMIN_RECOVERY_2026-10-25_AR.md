# عزل وتعافي شاشتي الإعدادات وإدارة المشاريع — 25 أكتوبر 2026

راجعت شاشة إعدادات المنصة وإدارة المطورين والمشاريع ضمن #14/#15/#16/#32. كان وصول استجابة إعدادات متأخرة يعيد إنشاء controllers حتى بعد dispose، كما احتفظت الشاشتان بحالة Stateful غير مرتبطة بالحساب. عرضت إدارة المشاريع الاستثناء التقني نصيًا، ولم توجد حالات فراغ صريحة أو رسالة إعادة محاولة موحدة داخل المحتوى.

يعيد الإصلاح استخدام `ActorScopedPage` الموجود، ويعزل الحالة حسب الحساب والصلاحيات. يُرفض الرد المتأخر قبل تخصيص controllers، وتُوقف سلسلة developers→projects إذا أُزيلت الصفحة أو تبدل الحساب. تعرض الشاشتان حالات التحميل والفراغ والفشل وإعادة المحاولة المشتركة. يحتفظ فشل 503 بالمحتوى وبمدخل الإعدادات المحلي غير المحفوظ؛ يمحو رفض 403 المحتوى السابق. تبقى صلاحيات Laravel والبوابات الحالية هي المرجع الأمني، ولم تتغير صلاحية أو عقد API.

أُضيفت ستة اختبارات widget لسلسلتي التحميل/503/retry/الفراغ، وحفظ المدخلات/الصفوف عبر 503 ثم إزالتها في 403، ورد حساب قديم بعد تبديل الحساب، ومنع استمرار طلب المشاريع القديم. تشمل حالات التحميل/الفشل/الفراغ ثيمًا داكنًا وتكبير نص 2.4. يظل قبول هاتف فعلي ومراجعة كل شاشة ثانوية منفصلين عن هذه الاختبارات؛ لا تُنسب تغطية التطبيق كله لإصلاح شاشتين.

لا تعديل Backend أو DB أو native/dependency، ولا حاجة إلى Render deploy لهذا النطاق.
