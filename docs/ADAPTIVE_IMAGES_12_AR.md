# عقار — جودة الصور المتكيفة #12

الفرع يبدأ من UAT الحالي `23ddba16d33e50b45a954d9d5e0d2dfe67737d8a`، وليس إصدارًا قديمًا. لا هجرة قاعدة ولا تبعية Flutter جديدة ولا تحويلات Supabase مدفوعة.

## التنفيذ
- Laravel ينتج JPEG آمنة من الأصل الخاص: thumb 320/64، card 640/80، preview 960/72، detail 1280/85، gallery 1920/88، zoom 3072/92. الأرقام طول الضلع الأقصى/جودة JPEG؛ لا تكبير اصطناعي للمصدر. النسخ القديمة ما زالت مدعومة، وتُولّد النسخة المفقودة المطلوبة وحدها.
- Flutter يغيّر عنوان variant الذي يُحمّل فعلًا، وليس cacheWidth فقط. القياس يعتمد مساحة العرض وكثافة الشاشة، وOS metered وData Saver. Wi-Fi لا تعني سرعة أو بيانات مجانية. النقل الفعلي في المقدمة يضيف إشارة بطء لمدة 60 ثانية تخص الشبكة نفسها؛ لا speed test ولا prefetch.
- المجهول أو الاتصال المحدود: بطاقات thumb، تفاصيل card. الاتصال غير المحدود يختار المقاس الموافق للشاشة. صور المصغرات thumb دائمًا. النسخة zoom لا تُطلب إلا بقرص التكبير أو زر المستخدم، مع إبقاء النسخة السابقة أثناء التحميل.
- طلبات الصور مشتركة داخل ذاكرة محدودة بالجلسة، بلا تخزين قرص. مغادرة آخر مستهلك تلغي الطلب المعلق. تبديل الحساب يمحو الكاش ويلغي الطلبات ويُخلي صور الذاكرة المفكوكة. لا يُرسل حساب عقار لخادم خارجي. صور المسودات والتفاصيل غير المنشورة تحمل المصادقة وتبقى no-store.
- Laravel يفحص الإتاحة قبل ETag؛ لا يستطيع 304 تجاوز تحويل الإعلان إلى مسودة. الأصل لا يُخدم كبديل عند الخطأ. ترتيب الصور ونشر الإعلان وحذفه لا يتغير بسبب قراءة نسخة أصغر.

## بوابات الإثبات
- `AdaptiveImageQualityTest`: حدود المقاسات/النوع والبيانات المنزوعة وقياس fixture اصطناعية، توليد تاريخي محدود، ETag والإتاحة وترتيب الصور.
- `adaptive_image_quality_test.dart`: شاشة/خلوي/Wi-Fi محدود/توفير البيانات/شبكة مجهولة، نقل بطيء مقاس وانتهاء عينته وتبديل الشبكة، عناوين مشتقات فقط، dedupe وإلغاء وكاش وتبديل جلسة.
- `probe_adaptive_images.py`: قراءة fixtures الاصطناعية المنشورة 60–62 فقط، gallery مقابل card للتفاصيل وcard مقابل thumb للبطاقات، و304 عند توفرها؛ تُقاس أزمنة فعلية دون تقييد وقراءة مضبوطة 64KiB/s كلٌّ على حدة. القراءة المضبوطة ليست محاكاة OS للشبكة الخلوية.
- `adaptive_image_uat_test.dart`: Flutter/Dio يقرأ API Laravel الحي ثم مشتقات التخزين الخاص عبر API؛ يثبت اختيار card لشبكة محدودة ونقلًا واحدًا عند العرض المتزامن والعودة.
- لا تُعتبر بوابة UAT الجديدة ناجحة قبل أن يذكر التقرير `adaptive_available=true` بعد النشر. القياسات قبل النشر تمثل baseline فقط. قبول Android Native على هاتف المالك ينتظر نسخة UAT موحدة لجميع البنود.
