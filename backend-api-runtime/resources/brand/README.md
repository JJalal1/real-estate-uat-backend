# Aqer vector activation gate

No production logo geometry is approved or shipped in this checkpoint. The owner handoff explicitly requires preview approval before production export. `aqer-approved.json` is intentionally absent; enabling watermarking without its exact approved SHA fails closed.

After approval, export normalized monochrome vector geometry: `{ "approval": "owner-approved", "layers": [{ "polygons": [[[0,0],[1,0],[0,1]]], "holes": [] }] }`. The triangle here documents the schema only and is not the Aqer identity. Coordinates must be finite in 0..1; polygon holes preserve the photo. Export the house/Yemen/wordmark contours from the approved canonical vector, never an ad id or a new generated logo. Record the owner approval and source SHA in the review documentation before adding the final file.

The local GD renderer uses repeated diagonal white at 10% and a 24% corner mark, generates private cached variants under a version derived from the approved fingerprint and keeps original bytes untouched. URLs gain that version only on explicit activation. This is a prepared inactive path, not a claim of live branded photos. Old derivative namespaces stay private pending an approved cleanup policy; shared originals are never deleted by watermarking.
